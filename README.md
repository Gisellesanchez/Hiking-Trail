## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Ensure that you are able to open the code in a compatible browser such as Google Chrome or Opera.
* When viewing the code you show be able to "Go Live" which will launch the HTML, CSS and Javascript into the browser, allowing you to view the Hiking Trail website. 
* When first opening the page for the first time it will ask you to share your current location with the website. This is to give you the most precise distance to each trail provided. 
    * If you choose not to share your location it will take the location of the center of the map and create distance from the center outward.
