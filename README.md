# Hiking Helper

I created this project with the simple goal of creating a GIS-based Hiking Helper for the location of Rexburg, Idaho. The information is displayed on an interactive map website. Allowing the user to click on acurrate markers to provide information about the hike, such as the trail difficulty, distance, if the trail is kid or pet friendly and a small description of the hike. The app also has a way to filter by the difficulty level, as well as hike distance. I was also able to demonstrate a basic understanding of GIS concepts through the map display, having a basemap aswell as a geographic interactive setting.  

## Instructions for Build and Use

[Software Demo](Put_Your_Video_Link_Here)

Steps to build and/or run the software:

1. Download or open the saved project files on your computer.
2. Open the project folder in Visual Studio Code
3. Make sure you are in the main file is which is 'index.html'.
4. Install and use the "Live Server" extension which is located at the bottom of the Visual Studio Screen as a button called "Go Live". 
5. This should open the 'index.html' file in a web browser if everything is created correctly. 
6. This is where you can see the front end of my project and interact with the map as well as all the filters and features. 

Instructions for using the software:

1. The first thing you will need to do is make sure that the Hiking Helper is able to be opened in your browser.
2. When you open the 'index.html' file for the first time it will ask you to share your loation with to get the most accurate precise location needed for this map to function properly. 
3. If you deny to share your location, the map will use the center of the map as a focal point. 
4. Use the search bar to look up a specific trail by name or the user can view the pins on the map.
5. The user can also filter by the differculty dropdown by Easy, Moderate, or Hard.
6. There is a sort option to sort through the closest distance or by name of the trail. 
7. The user can switch between the road basic map or the topographic map option, through the basemap dropdown.
8. Click on any trail maker on the map to view the trail information such as the name, differculty, distance, and if the trail is pet and or kid  friendly
